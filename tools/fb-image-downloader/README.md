# ดึงรูปจากโพสต์ Facebook ลงคอม

สคริปต์สำหรับโหลดรูปทุกโพสต์จาก Facebook ลงเครื่องคอมพิวเตอร์ของคุณ
ใช้ Python อย่างเดียว ไม่ต้องติดตั้งอะไรเพิ่มก็ใช้ได้ (วิธีที่ 1)

> **หมายเหตุ:** ต้องรันบนคอมของคุณเอง ไม่ใช่บน Claude Code
> เพราะเซิร์ฟเวอร์ของ Claude บล็อก facebook.com ไว้ และไฟล์ที่โหลดต้องลงเครื่องคุณ

## เตรียมตัว

1. ติดตั้ง [Python 3](https://www.python.org/downloads/) (ถ้ายังไม่มี)
   ตอนติดตั้งบน Windows **ติ๊กช่อง "Add Python to PATH" ด้วย**
2. โหลดไฟล์ `fb_images.py` จากโฟลเดอร์นี้ไปไว้บนคอม
3. เปิด Terminal (Mac) หรือ Command Prompt / PowerShell (Windows)
   แล้ว `cd` เข้าไปที่โฟลเดอร์ที่วางไฟล์ไว้

---

## วิธีที่ 1 — เซฟหน้าเว็บแล้วดึงรูป (ง่ายสุด ไม่ต้องล็อกอินซ้ำ)

เหมาะกับ: โพสต์เดียว หรืออัลบั้มที่เปิดดูได้อยู่แล้ว

1. เปิดโพสต์ที่ต้องการในเบราว์เซอร์ (ล็อกอิน Facebook ตามปกติ)
2. **เลื่อนหน้าลงจนสุด** ให้รูปโหลดขึ้นมาครบทุกใบก่อน
   (Facebook โหลดรูปแบบทยอยขึ้น ถ้าไม่เลื่อนจะได้ไม่ครบ)
3. กด `Ctrl + S` (Windows) หรือ `Cmd + S` (Mac) → เลือก **Webpage, Complete**
   → เซฟเป็นไฟล์ เช่น `post.html`
4. รันคำสั่ง:

```bash
python3 fb_images.py --from-html post.html
```

รูปทั้งหมดจะไปอยู่ในโฟลเดอร์ `fb-images`

เซฟไว้หลายหน้าก็ใส่ทีเดียวได้เลย:

```bash
python3 fb_images.py --from-html post1.html --from-html post2.html --from-html post3.html
```

## วิธีที่ 2 — ใส่ลิงก์ตรงๆ (ดึงได้ทีละหลายโพสต์)

เหมาะกับ: อยากได้ **รูปทุกโพสต์ของทั้งเพจ** ในคำสั่งเดียว

ติดตั้งตัวช่วยก่อน (ทำครั้งเดียว):

```bash
pip install gallery-dl
```

แล้วรัน โดยบอกให้ดึงคุกกี้ล็อกอินจากเบราว์เซอร์ที่คุณใช้อยู่:

```bash
python3 fb_images.py "https://www.facebook.com/share/1H39U7eKbP/" --browser chrome
```

เปลี่ยน `chrome` เป็น `firefox`, `edge`, `safari` หรือ `brave` ตามที่ใช้จริง

**ถ้าอยากได้ทุกโพสต์ของเพจ** ให้ใส่ลิงก์หน้ารูปภาพของเพจแทน:

```bash
python3 fb_images.py "https://www.facebook.com/ชื่อเพจ/photos" --browser chrome
```

สคริปต์จะขยายลิงก์ `/share/xxxx/` เป็นลิงก์โพสต์จริงให้อัตโนมัติ

### ถ้า `--browser` ใช้ไม่ได้

บางเครื่องอ่านคุกกี้จากเบราว์เซอร์ไม่ได้ (โดยเฉพาะ Chrome เวอร์ชันใหม่บน Windows)
ให้ export คุกกี้เป็นไฟล์แทน ด้วยส่วนขยาย **Get cookies.txt LOCALLY**
([Chrome](https://chromewebstore.google.com/detail/get-cookiestxt-locally/cclelndahbckbenkjhflpdbgdldlbecc))
แล้วรัน:

```bash
python3 fb_images.py "ลิงก์โพสต์" --cookies cookies.txt
```

## วิธีที่ 3 — มีลิงก์รูปอยู่แล้ว

ใส่ลิงก์รูปในไฟล์ text บรรทัดละ 1 ลิงก์ (ตั้งชื่อ `urls.txt`) แล้ว:

```bash
python3 fb_images.py --from-list urls.txt
```

## ตัวเลือกเพิ่มเติม

| คำสั่ง | ความหมาย |
|---|---|
| `-o โฟลเดอร์` | เปลี่ยนที่เก็บรูป (ค่าเริ่มต้น `fb-images`) |
| `--limit 50` | เอาแค่ 50 รูปแรก |
| `--dry-run` | ดูรายชื่อไฟล์ก่อน ยังไม่โหลดจริง |
| `--min-size 30000` | ข้ามไฟล์เล็กกว่า 30 KB (กันไอคอน/รูปโปรไฟล์เล็กๆ ปน) |
| `--no-gallery-dl` | ไม่ใช้ gallery-dl ให้ดึงเองตรงๆ |

ตัวอย่าง — ดูก่อนว่าจะได้อะไรบ้าง แล้วค่อยโหลดจริง:

```bash
python3 fb_images.py --from-html post.html --dry-run
python3 fb_images.py --from-html post.html -o "D:\รูปสินค้า"
```

## สิ่งที่สคริปต์ทำให้อัตโนมัติ

- **เลือกไฟล์ความละเอียดสูงสุด** — Facebook ใส่รูปเดียวกันหลายขนาดในหน้าเว็บ
  สคริปต์จะตัดพารามิเตอร์ย่อขนาด (`stp=`) ออก แล้วเลือกไฟล์ต้นฉบับ (`_o`/`_n`) ให้
- **ไม่โหลดซ้ำ** — รูปเดียวกันที่มีหลายขนาดจะนับเป็นใบเดียว
- **ข้ามไอคอนกับอิโมจิ** — ตัดพวก `rsrc.php`, emoji, และไฟล์ที่เล็กเกินไปออก
- **รันซ้ำได้** — ไฟล์ที่โหลดไว้แล้วจะข้าม โหลดต่อจากเดิมได้เลย
- **ลองใหม่อัตโนมัติ** 3 ครั้ง ถ้าเน็ตหลุด

## ปัญหาที่เจอบ่อย

| อาการ | วิธีแก้ |
|---|---|
| `No images found` | ยังเลื่อนหน้าไม่สุดก่อนเซฟ หรือเซฟแบบ HTML Only — ต้องเลือก **Webpage, Complete** |
| เจอหน้า login | ต้องใส่คุกกี้ — ใช้ `--browser` หรือ `--cookies` |
| ได้รูปไม่ครบ | Facebook โหลดทีละส่วน ให้เลื่อนจนสุดจริงๆ แล้วเซฟใหม่ หรือใช้วิธีที่ 2 |
| ได้รูปเล็กๆ ที่ไม่ต้องการปนมา | เพิ่ม `--min-size 50000` |
| `python3: command not found` | บน Windows ลองใช้ `python` แทน `python3` |

## ข้อควรระวัง

ใช้ดึงรูปที่คุณมีสิทธิ์เข้าถึงและมีสิทธิ์นำไปใช้เท่านั้น
รูปของคนอื่นมีลิขสิทธิ์ของเจ้าของโพสต์ ควรขออนุญาตก่อนนำไปใช้ในเว็บ
